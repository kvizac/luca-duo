Both open in an embedded privacy-enhanced YouTube player.

Run locally:
1. Open index.html directly, or
2. From this folder run: python -m http.server 8000
3. Open http://localhost:8000

The booking form is still a front-end demo and does not submit data.
The biography, repertoire details and contact information are placeholder copy until final content is supplied.

GitHub Pages:
A ready-to-use workflow is included at .github/workflows/pages.yml.
After the files are pushed to a public GitHub repository, open:
Settings > Pages > Build and deployment > Source > GitHub Actions.
Then push to main (or run the workflow manually) and GitHub will publish the site.
